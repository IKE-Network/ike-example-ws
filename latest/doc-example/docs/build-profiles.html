Build Profiles

The documentation pipeline uses a property-driven build pattern. All build logic lives in the main <build> section of ike-parent/pom.xml, with per-renderer skip flags that default to true. Profiles are thin toggles that flip their skip flag to false. This makes profiles discoverable in IntelliJ’s Maven Profiles panel and composable via -D properties or -P flags.

Profiles are composable. Activate multiple renderers in a single build by passing multiple properties: mvn clean verify -Dike.pdf.prawn -Dike.pdf.fop -Dike.pdf.xep. The html profile is active by default and does not need to be specified.

Skip Properties

Each renderer has a skip flag that defaults to true (disabled). Profiles flip the relevant flag to false. You can also override skip flags directly from the command line.

ike.skip.fop

true

FOP pipeline + ZIP

ike.skip.pdf-default

true

Default PDF copy + ZIP

ike.skip.docbook

true

DocBook XSL unpack (shared by XEP and FOP)

Override skip flags directly:

# Enable HTML + Prawn without using profiles
mvn clean verify -Dike.skip.html=false -Dike.skip.prawn=false

Maven Build Commands

The reactor build is invoked directly with Maven, using -D properties to select PDF renderers:

mvn clean verify                       # HTML only (default)
mvn clean verify -Dike.pdf.prawn       # Prawn PDF
mvn clean verify -Dike.pdf.fop         # DocBook -> XSL-FO -> FOP (free)
mvn clean verify -Dike.pdf.xep         # DocBook -> XSL-FO -> XEP
mvn clean verify -Dike.pdf.prince      # HTML -> Prince XML -> PDF
mvn clean verify -Dike.pdf.ah          # HTML -> AH Formatter -> PDF
mvn clean verify -Dike.pdf.weasyprint  # HTML -> WeasyPrint -> PDF

The Maven reactor:

  1. Validates prerequisites (Maven, Java, renderer binaries)

  2. Builds infrastructure modules first (sorted by dependency graph)

  3. Builds doc projects with the selected renderer

  4. For Prawn: runs svgo to inline CSS in SVGs, then rebuilds

All renderer executions are declared in the main <build> section with per-renderer <skip> flags that default to true. Profiles are thin toggles that set ike.skip.RENDERER=false. The pom-skip-renderers profile (activated by <packaging>pom</packaging>) forces external renderer skip flags back to true for POM-packaging modules like ike-parent, even when renderer profiles are active. HTML and Prawn are left alone since asciidoctor-maven-plugin handles missing sources gracefully.
